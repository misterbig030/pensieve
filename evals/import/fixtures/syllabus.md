# Introduction to Statistical Learning: Course Syllabus

This course covers the core ideas of statistical learning. Students should know basic calculus and linear algebra.

## Topics

- Linear regression: least squares, inference on coefficients, diagnostics
- Classification: logistic regression, linear discriminant analysis, k-nearest neighbors
- Resampling: cross-validation and the bootstrap
- Model selection and regularization: subset selection, ridge, lasso
- Tree-based methods: decision trees, bagging, random forests, boosting
- Support vector machines
- Unsupervised learning: principal components, clustering

## Textbook

James, Witten, Hastie and Tibshirani, *An Introduction to Statistical Learning*, 2nd edition.

## Grading

Problem sets 40%, midterm 25%, final project 35%.
