# Learn Rust in a Quarter

A three-month plan to go from reading the book to shipping a small command-line tool. About six hours a week.

## Month 1 · January · The language

Work through *The Rust Programming Language* chapters 1-10: ownership, borrowing, structs, enums, error handling,
generics and traits. Do the Rustlings exercises for each chapter as you finish it.
Goal: explain ownership and lifetimes to a friend without notes.

## Month 2 · February · Real programs

Chapters 11-17 of the book: tests, closures, iterators, smart pointers, concurrency. Rewrite two small scripts you
already use (a log filter and a file renamer) in Rust and compare them with the originals.
Goal: both scripts replaced and tested.

## Month 3 · March · Ship a tool

Build a command-line tool of your own with `clap` and `serde`, such as a markdown link checker. Write tests, set up
CI, and publish a release on GitHub. Read *Rust for Rustaceans* chapters 1-4 alongside for idiom.
Goal: a tagged v0.1 release that someone else can install.
