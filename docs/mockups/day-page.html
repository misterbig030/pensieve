Back-of-the-envelope estimation

Yesterday you learned how to think about scaling a system. Every one of those decisions hides a numbers question: how many machines, how much storage, how fast. Today is about answering them in your head, to the nearest order of magnitude.

STEP 1Read chapter 2 up to the worked example. Copy the latency table onto paper.25 min

The three tables worth memorising

You don't need exact figures, only the gaps between them. Memory is about a hundred times faster than a solid-state disk, which is a hundred times faster than a round trip across continents.

L1 cache reference0.5 nsMain memory reference100 nsRead 1 MB from SSD1 msRound trip, CA to Netherlands150 ms
