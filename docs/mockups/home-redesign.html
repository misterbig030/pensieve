Week 2 · Day 9 · Today

The borrow checker in practice

Yesterday you met the three borrowing rules. Today you watch the compiler enforce them, then fix five broken programs until they compile.

Two kinds of loan

Every value has one owner, and the owner can lend it out in two ways: as many shared references (&T) as you like, or exactly one mutable reference (&mut T). Never both at once.1 The borrow checker is the part of the compiler that rejects any program where the two overlap.

// a shared borrow is still alive when we try to change the vector
let mut scores = vec![90, 72];
let first = &scores[0];
scores.push(88);
println!("{first}");

error[E0502]: cannot borrow `scores` as mutable because it is also borrowed as immutable
Two fixes: print first before the push, or copy the number out with let first = scores[0]; so nothing is borrowed.
